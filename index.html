Technical Blueprint

全校級 AI 協作生態系技術架構圖

採用「全端無伺服器 (Serverless)」+「Google Workspace 深度整合」+「Gemini 雙模態推理」架構，具備高擴充性、高資安防護與零維護預算優勢。

1. 前端多載具適應層

  • • HTML5 / Tailwind CSS / Vanilla JS
  • • 跨手機、平板、大型電子白板 RWD
  • • 免登入/驗證雙軌模式，兼顧平權與防偽
  • • 採用 GitHub Pages 進行全球 CDN 高速分發

2. AI 智能推理與辨識層

  • • Google Gemini 1.5 / 2.5 Flash 多模態 API
  • • 公文與通知之自然語言實體命名辨識 (NER)
  • • 手寫筆記與美育畫作之 Multimodal Vision OCR
  • • 去識別化提示詞工程 (Zero PII Exposure)

3. 雲端後端與行政報表層

  • • Google Apps Script 伺服器端核心
  • • LockService 併發鎖杜絕名額超額與搶位
  • • 自動寫入 Google Sheets 即時動態總表
  • • 自動排版生成 Google Docs 符合教育局檢核手冊

大溪智慧校園 AI 協作矩陣

提案學校：桃園市立大溪國民中學 ｜ 代表人：游貿仁 老師 ｜ 徵件組別：智慧行政（兼精進教學創新與班級經營）

1 問題描述與需求分析 (25%)

中小學校園長期面臨行政繁重（公文重打、會議撞期、紙本收件建檔）與教學分流痛點（選社盲選、素養評量枯燥）。傳統單點工具難以貫通全校跨處室流程。本案打造全方位 Agent 生態系，從公文排程、自主學習歷程、社團志願分發到跨學科遊戲化評量，一次性徹底解決各處室痛點。

2 突破亮點 (25%)

【全端跨域整合】首創串連行政、輔導、創客與遊戲化評量；【併發防護演算法】導入 LockService 杜絕搶名額爭議；【多模態端到端】手寫筆記與美育畫作直接透過 Vision AI 轉為結構化報表與創客印刷檔，真正落實「零手動重複輸入」。

3 功能簡介與初步實現步驟 (25%)

涵蓋六大子系統：AI 行事曆排程防撞、學習軌跡免登入多模態助教、適性社團多志願分發、美育創客胸章掃描儀、質數守門塔防遊戲與跨學科雙人搶答對決。六大作品皆已 100% 實現並上線運作，在校內實際班級進行常態化驗證，成熟度極高。

4 預期效益 (25%)

【量化工時節省 90% 以上】：會議排程由 20 分減至 2 分鐘、期末成果冊由 10 小時減至 15 秒、選社分發由 1 週縮減至 5 分鐘內。【質化影響】：保障弱勢學生平權、激發學習動能，全校節省之數百小時工時徹底回歸教學與學生輔導。
